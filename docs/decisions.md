# Decisions

Defaults chosen where the kickoff left things open. Each one is cheap to change; the "where" column says how.

| # | Decision | Why | Where to change |
|---|----------|-----|-----------------|
| 1 | Vite `base` comes from the `BASE_PATH` env var; GitHub Actions sets it to `/<repo>/`, local dev uses `/`. | Keeps local dev at `http://localhost:5173/` and still works on GitHub Pages. For a custom domain set the `BASE_PATH` repository variable to `/`. | `vite.config.ts`, `.github/workflows/deploy.yml` |
| 2 | Sign-in codes: both the "Confirm signup" and "Magic Link" email templates render `{{ .Token }}`. | Supabase sends "Confirm signup" on a user's first sign-in and "Magic Link" afterwards; both must show the code or first-time users get a link. | `supabase/config.toml` (local), Auth → Email Templates (hosted) |
| 3 | Keep-alive runs Monday and Thursday 06:00 UTC and calls `public.ping()` via PostgREST. | Twice a week leaves slack if one run fails; an RPC guarantees a real query reaches Postgres. | `.github/workflows/keepalive.yml` |
| 4 | CI runs lint, typecheck, Vitest, a build with placeholder env, and the pgTAP suite on a throwaway local Supabase. | Database rules are the core of the app; they must be tested on every PR, not just locally. | `.github/workflows/ci.yml` |
| 5 | Placeholder PWA icons are generated by `scripts/make-icons.mjs` (CETIN blue background, white desk, red seat). | No design assets yet; the script needs no image libraries. Replace the PNGs in `public/` with real artwork any time. | `public/`, `npm run icons` |
| 6 | UI strings live in `src/strings.ts` as one typed object; error codes raised by the database map 1:1 to `strings.errors`. | A Czech version becomes a second object with the same shape. | `src/strings.ts` |
| 7 | Theme uses CETIN brand colours (CETIN Blue `#300091`, red `#f12e49`, digital background palette) and Avenir → Arial. | Internal CETIN tool; follows the brand guide without embedding the logo. | `src/index.css` |
| 8 | Supabase CLI is a dev dependency (`npm run db:*`), not a global install. | Same CLI version for everyone and in CI. | `package.json` |
